# AAKNAV Funding Management Application

Android internal management app for AAKNAV Invest Private Limited.

## Included modules
- Dashboard
- Customers
- New Application: Startup Funding, Working Capital, Business Expansion, Business Support
- Application tracking
- Collections overview
- Reports
- AAKNAV blue/white/yellow branding
- Local on-device customer/application storage
- GitHub Actions APK build workflow

## Build
The included GitHub Actions workflow builds a debug APK automatically on pushes to `main` or manually from Actions > Build AAKNAV APK > Run workflow.

## Important
This is an initial internal-app build. Before using it for real customer financial/KYC data, add secure authentication, encrypted storage, server-side database, audit logs, role-based permissions, document security, backups, and the required legal/compliance controls.
